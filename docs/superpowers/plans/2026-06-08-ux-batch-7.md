## 1. 错误以 agent 发言显示在会话框
有会话的流程(选股/个股分析/早会/晚会/核心原则)出错时,把错误作为**助手消息**写进对应会话,而非只弹 banner。
- 后端:`chat/service.ts` 加 `addAssistantNote(userId, sessionId, content)`(直接 `addMessage(sessionId,'assistant',content)`,不调 AI);路由 `POST /chat/sessions/:id/note {content}`(鉴权+own校验)。`chat.ts` api 加 `postNote(id, content)`。
- 前端 `HomeView`:`genMeeting`/`runScreen`/`doAnalyze`/`propose`/`synthesizePrinciple`/`applyProposal`/`applyCompose` 等 catch 里,若有对应会话 id → `await chatApi.postNote(sid, '⚠️ '+msg)` 并把返回消息 push 进 `messages`(active 时);保留 genErr 作兜底但次要。
- 验证:制造一个失败(如无模型时生成早会)→ 会话里出现 ⚠️ 助手消息且刷新后仍在。

## 2. 消息气泡 3 行折叠 + 详细弹层(markdown)
- 前端加依赖 `marked`(轻量 md);加 `frontend/src/utils/md.ts`(`renderMarkdown(text)`,marked + 基本转义)。
- 新组件 `frontend/src/components/ClampText.vue`:props `text`;渲染一个 `.clamp`(CSS `-webkit-line-clamp:3`)显示纯文本;`onMounted`/`watch` measure `scrollHeight>clientHeight` → 显示「详细」按钮;点击 `emit('detail')` 或自身打开模态。
- 模态层 `frontend/src/components/MarkdownModal.vue`(或 HomeView 内联):全屏遮罩 + 居中卡片,`v-html=renderMarkdown(text)`,右上角关闭。
- `HomeView` 消息渲染:`<div class="bubble"><ClampText :text="m.content" @detail="openDetail(m.content)" /></div>`;`briefing` 块同样用 ClampText。一个共享 `detailText` ref + MarkdownModal。
- 应用范围:**所有消息气泡(用户+agent)** + briefing/screen 文本。短消息(≤3行)不显示详细按钮。
- 验证:长消息折叠成 3 行 + 详细按钮;点开弹层 markdown 渲染(标题/列表/加粗);短消息无按钮;vue-tsc 通过。

## 3. 「立即更新」点击即出进度条
- `DataView.doRun`:点击后**乐观**立即把 `jobs[job]` 置为 `{state:'running', done:0, total: jobs[job]?.total||0, message:'启动中…'}` → 立即显示进度条;随后 `await runJob` + `refreshJob` + 确保轮询计时器在跑。
- 验证:点立即更新,进度条/「启动中…」立刻出现,不再"等一会才变"。

## 4. admin 始终能看到后台任务进度 + 强制中止;无任务才可点更新
- `DataView`:轮询计时器(`jobTimer`)在**进入页面即启动、每 ~2.5s** 刷新 stock_universe/eod 状态(不依赖是否已知 running);running 时显示进度条 + `取消`/`⛔强制中止`(admin);idle 时显示`立即更新`(沿用 canRun:running 或今日已成功 → 禁用)。
- 顶部「状态概览条」对 admin 增一行:有任务时显示「后台正在:<job> done/total」+ 强制中止入口(复用现有)。
- 验证:用脚本起一个 eod 任务 → 切到数据页能看到进度条 + 强制中止;中止后变回可更新。

## 5. 出站取数:伪装 header + 防 429
- `sidecar/main.py` 顶部加 `_install_http_hardening()` 并在 import 时调用:
  - 给 `requests`(akshare 底层)默认会话装**浏览器 UA**(`Mozilla/5.0 ... Chrome/...`)+ `Accept-Language` 等;monkeypatch `requests.sessions.Session.request`,若无 `User-Agent` 头则注入。
  - 给默认 `HTTPAdapter` 挂 `urllib3.util.retry.Retry(total=4, backoff_factor=0.6, status_forcelist=[429,500,502,503,504], respect_retry_after_header=True)`,`requests.Session` 默认 mount。
- 验证:容器内 `python -c "import requests; r=requests.get('https://httpbin.org/headers'); print(r.json())"` 头里有浏览器 UA;akshare 取数仍正常(`/quote /fundamentals` 实测)。

## 6. 股市日历:封顶到当年(11/30 后到明年)+ 每次打开回到当前月
- `HomeView`:计算 `maxYear/maxMonth`:`afterNov30 = month>11 || (month===11 && day>=30)`;`maxYear = afterNov30 ? cy+1 : cy`,`maxMonth=12`。`nextMonth` 到 `(maxYear,12)` 时禁用(模板 `:disabled` + 函数内 guard)。
- `toggleCalendar` 打开时:`calYear=当前年; calMonth=当前月`(每次打开都重置,不记忆上次);随后 load。
- 后退保留(看历史)。
- 验证:日历默认当前月;往后翻最多到当年12月(今天是 6/8 → 封顶 2025/2026 当年12月);关闭再开仍回当前月。

## 7. 会话窗口「清理」按钮(清空当前会话,持久化)
- `HomeView` 标题区(`active` 时)加 `🧹 清理` 按钮 → `clearCurrent()`:`confirm` → `await chatApi.clearMessages(active.id)` → `messages.value=[]`。持久化(DB 删)。
- 与左栏「清空所有对话」区分(那个清全部)。
- 验证:点清理 → 当前会话清空,切走再回仍空。
